# Decision records

[Planning ADRs](../../docs/planning/architecture-decisions.md) retain their existing IDs/statuses. [Product decisions](../../docs/planning/decisions.md) retain confirmed business choices. Slice records explain concrete implementation alternatives and link these documents rather than replacing them.

Current: [Slice 0 proposed decisions](slice-0.md). Each decision links requirements, issues once created, files/classes, DB/API impact, tests and verification. Status starts proposed; only a scoped user approval changes it to accepted.
